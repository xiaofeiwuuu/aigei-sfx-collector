# Aigei SFX Collector

在 [爱给网](https://www.aigei.com/) 音效页面的每条音效旁注入一个「直接下载」按钮,并支持一键下载当前页的全部试听音频。Chrome / Edge 通用(Manifest V3)。

> 下载的是网站提供的**试听版**音频(约 64kbps mp3),不是 wav / HQ 正式文件。

## 功能

- 每条音效旁出现红橙色的「直接下载」按钮,点击后保存到浏览器下载目录的 `aigei/` 子文件夹,文件名为 `<音效ID>_<标题>.mp3`。
- 页面右下角浮窗:**下载本页全部试听**,可随时点「停止」。
- 适配四种页面布局:音效列表页、热门卡片、音效详情页(`/item/`)、专辑页(`/set/`)。
- 如果你已经手动试听过某条,会直接复用网站已缓存的链接,不再重复请求。
- 按钮状态:处理中(灰)、已下载(绿)、失败(深红,附原因)。

## 安装

1. 下载或 clone 本仓库。
2. Chrome 打开 `chrome://extensions`,Edge 打开 `edge://extensions`,开启「开发者模式」。
3. 点「加载已解压的扩展程序」(Edge 为「加载解压缩的扩展」),选择本仓库目录。
4. 打开爱给网的音效页面,刷新后即可看到按钮。

要求 Chromium 111 及以上(`content_scripts` 的 `world: "MAIN"` 需要)。每次修改代码后,需在扩展页点「重新加载」并刷新目标页面。

## 工作原理

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 配置。仅申请 `downloads` 权限,匹配 `https://www.aigei.com/*`。 |
| `inject.js` | 运行在页面上下文。包装站点自己的 `callBackAudioFilePlay` 以读取试听链接;并按需读取站点播放器对象上已缓存的链接。不发起任何网络请求。 |
| `content.js` | 运行在隔离环境。注入按钮和浮窗;取链接时先查缓存、再点击站点的播放按钮;在页面里请求音频字节(浏览器自动带上站点 Referer)。 |
| `background.js` | 仅负责把音频字节保存为文件。 |

为什么下载要在页面里发起:站点的音频 CDN 要求请求带 `aigei.com` 的 Referer,插件后台请求没有,会返回 403。

## 限制与注意

- **只有试听版**。正式格式(wav、HQ mp3、mp4)需要站点会员额度,下载请求带有站点的动态签名,本项目**不绕过**这些限制,也不提供正式版下载。
- **链接会过期**。试听链接带有过期时间(约一两小时),取到后请尽快下载。
- **只处理当前页**,不会自动翻页。批量下载为串行执行并带随机间隔;超过 30 条会先弹窗确认,连续 3 条失败会自动停止。
- **页面改版会失效**。选择器依据当前页面结构编写,站点更新后可能需要调整。
- 已在 Chrome 中测试;Edge 理论兼容(同为 Chromium),但未做完整测试。
